# filtrationX

filtrationX 是一款**本地优先的 X（原 Twitter）浏览器扩展**，基于 `make-x-great-again` 二次开发，开源协议 AGPL-3.0，用来自动识别、过滤 X 平台上广告号、色情机器人等垃圾账号。

> 核心特点：**匹配逻辑本地运行，默认不上传你的浏览数据**

## 核心能力

### 继承上游 MXGA 的基础功能

1. 社区公开黑名单：每 6 小时自动同步，在本地完成账号匹配
2. 关键词过滤：内置官方规则 + 支持自定义关键词
3. 处理动作可选：仅标记、本地隐藏、X 平台原生静音、X 平台原生拉黑
4. 可选在线 AI 检测；本地白名单优先级最高，不会被过滤

### 本项目新增增强功能

- 自定义词库双向同步：本机规则 ↔ 你自己的 GitHub 仓库，登录后自动识别账号与可写仓库，带权限校验
- 白名单账号迁移：账号改名后，可以迁移白名单资格
- 黑名单批量拉黑保护：自带限速、单次上限、失败熔断机制，降低账号风控风险；已封禁 / 注销的账号自动跳过并缓存
- 拉黑列表同步：读取你在 X 上已经拉黑的账号，断点续传 + 分页浏览，支持一键解除拉黑
- 本地反养号启发式：识别互关农场、问候模板刷屏、高频发帖、电商促销墙等行为指纹，任意位置判垃圾全站统一标记
- NSFW&成人榜单：聚合福利鉴 / Archive 榜 / NSFW.pet 三个公开榜单（仅存本机），按筛选构建队列一键关注，同一套限速熔断基建
- 动作开关：默认只在本地隐藏垃圾账号，可手动开启自动静音 / 拉黑策略
- KOL 可信悬浮卡片：鼠标悬停用户 ID，展示账号年龄、原创占比、内容集中度、发帖量、可信评分（本地采样，可选 GraphQL 提升精度）
- UI 多语言：跟随浏览器语言，支持中 / 英 / 日；干净账号带有绿色标识

## 安装方式

### 普通用户（推荐）

1. 前往 [Releases](https://github.com/xiaoyi36c/filtrationX/releases) 页面，下载 `filtrationX-*-chrome-mv3.zip` 压缩包并解压
2. Chrome 类浏览器打开扩展管理页 `chrome://extensions`，打开开发者模式
3. 选择「加载已解压的扩展程序」，选中解压后的文件夹
4. 打开 [x.com](https://x.com) 即可自动生效

> ⚠️ 提示：如果你原本安装了原版 MXGA，建议先禁用，避免冲突

### 源码构建

```bash
git clone https://github.com/xiaoyi36c/filtrationX.git
cd filtrationX/extension
npm install
npm run build
```

构建产物输出在 `.output/chrome-mv3`

### 可选自部署服务端

用于开启白名单账号自动改绑迁移功能，不部署不影响扩展绝大多数功能；部署后在扩展设置 - 高级里填写你的服务地址即可。

## 隐私说明

账号、浏览内容等数据**只保存在本地**；词库同步仅读写你指定的 GitHub 仓库文件；拉黑操作复用你浏览器里的 X 登录态，不会上传你的浏览信息。隐私文档与开源许可证在仓库内可查阅。
