# filtrationX

[![Upstream](https://img.shields.io/badge/upstream-MXGA%20v0.6.1-444)](https://github.com/foru17/make-x-great-again)

filtrationX 是 [Make X Great Again (MXGA)](https://github.com/foru17/make-x-great-again) 的二开分支。上游做了社区公开黑名单、本地关键词匹配和在线 AI 检测；这个分支在其之上补了几件日常用得上的事——自己的词库自己托管、批量拉黑有节奏地执行、误拉黑能恢复、悬停在 @handle 上能看出一个账号靠不靠谱。

所有数据默认只存在本机；上游的完整文档、治理规则与隐私说明见[原仓库](https://github.com/foru17/make-x-great-again)。

## 功能一览

| # | 功能 | 入口 |
|---|------|------|
| F1 | 自定义词库同步到自己的 GitHub 仓库 | 设置 → 检测规则 → 自定义规则 |
| F2 | 白名单改绑新的 X id | 白名单页 → 已批准面板 |
| F3 | 黑名单一键拉黑（限速、可暂停、可续跑） | 概览页 → 「黑名单一键拉黑」 |
| F4 | X 原生拉黑列表同步与误拉黑恢复 | 概览页卡片 → 侧边栏「拉黑同步」 |
| F5 | 本地规则命中也执行设定的动作 | 设置 → 自动处理策略 |
| F6 | KOL 悬浮卡（上游目标 02） | 悬停任意 @handle |

这些功能与上游并行生效、互不影响。下面按使用频率展开说。

## 各功能说明

### F1 · 词库托管到自己的仓库

自定义关键词以 JSON 文件（默认 `mxga-custom-rules.json`）存在你自己的仓库里：

- 本机增删关键词后自动推送；在 GitHub 网页上直接编辑，每 6 小时自动合并回本机，也可以手动双向同步
- 登录后自动识别你的账号和可写仓库，不用手填 owner/repo
- 上传前校验令牌写权限；官方同步下来的关键词照常生效，两套词库互不影响

### F2 · 白名单改绑

账号改名后，已批准的官方白名单名额可以迁到新 id。新 id 取自当前登录的 X 账号，与首次申请同一套鉴权和人工审核；批准时名额自动迁移，旧 id 退出白名单并保留审计。自动改绑端点需要自部署 edge，未部署时扩展会生成预填好的 GitHub Issue 走人工通道。

### F3 · 黑名单一键拉黑

把公共黑名单条目用你的 X 登录态批量原生拉黑。节奏是刻意放慢的：后台泵 2.5 秒加随机抖动，叠加上层 1.2 秒限速队列，实际约 4–5 秒一个；单次执行量自选（100 / 300 / 500），连续 5 次失败自动停。

- 执行需要一个打开的 x.com 标签页（拉黑请求必须由 x.com 页面发出），支持暂停 / 继续 / 停止
- 进度本地持久化，关浏览器不丢，1 分钟看门狗自动续跑
- 已处理过、白名单和你自己的账号一律跳过，结果落账到「处理记录」

### F4 · 拉黑同步与误操作恢复

把 X 账号过往已拉黑的账号拉回来看——新装扩展显示 0，点「同步拉黑列表」分页拉取（只读，每页 200 个，页间自动停顿），存进侧边栏「拉黑同步」页。误拉黑的账号在行内点「解除拉黑」即恢复，走同一套限速队列。同步和解除都只存本机。

### F5 · 本地规则命中也执行动作

默认关闭，此时关键词命中最多本地隐藏。开启后规则命中按各类别设定的动作执行（含 X 静音 / 拉黑），仍受自动收录档位与「仅推文评论区」范围限制。

### F6 · KOL 悬浮卡

悬停在 @handle 上，浮卡展示账号年龄、粉丝规模、赞粉比，以及本地采样得出的原创比、主题集中度和综合可信分（靠谱 / 一般 / 存疑 / 高风险四档）。档案数据来自页面自身（React fiber 桥），采样随浏览累积——只存词频计数，不存推文原文，全程不联网。

设置里可选开启「精确互动质量」：悬停时按需拉取最近 20 条推文，计算单条获赞 / 转推 / 回复中位数与粉丝数的比值，买粉号和刷赞号在这一项上现形。默认关闭，开启后走独立读限速（≥400ms 间隔、429 冷却 10 分钟），结果缓存 3 天。

其他界面能力：全局多语言（中文 / English / 日本語，默认跟随浏览器语言，语言页可改）；AI 判定干净的账号显示低调的「已检」标，悬停可手动处理。

## 安装

1. 从 [Releases](https://github.com/xiaoyi36c/filtrationX/releases) 下载 `filtrationX-v0.2.2-chrome-mv3.zip`，或自行构建：

   ```bash
   cd extension
   npm install
   npm run build
   ```

2. 解压后打开 `chrome://extensions`，开启「开发者模式」，加载已解压的扩展程序。
3. 访问 x.com，扩展自动开始工作。

加载前建议先停用商店版 MXGA，避免两个扩展同时检测同一页面。

## 服务端（可选）

`services/edge` 新增 `POST /v1/whitelist/apply/rebind`，与首次申请共用 GitHub 身份和反滥用校验，要求名下存在仍生效的已批准申请；配套迁移 `services/edge/migrations/2026-10-24-whitelist-rebind.sql`。不部署不影响扩展其他功能；自部署后在「设置 → 高级」里把服务地址改成你的 Worker 即可。
