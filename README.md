# filtrationX

基于 [Make X Great Again (MXGA)](https://github.com/foru17/make-x-great-again) v0.6.1 的二次开发分支（当前版本 **v0.2.01**，AGPL-3.0），扩展名 `filtrationX（MXGA 二开版）`。安装包见 [Releases](https://github.com/Bycorer/filtrationX/releases)。
MXGA 是一个 X（Twitter）垃圾号过滤扩展：社区共建公开黑名单 + 本地关键词匹配，帮你把广告号和色情 bot 标出来。上游的完整文档、治理规则与隐私说明见[原仓库](https://github.com/foru17/make-x-great-again)。

本分支保留上游全部能力（官方关键词、公共名单 6 小时同步、本地隐藏 / 静音 / 拉黑、在线 AI 检测等），并新增以下四项功能，与上游功能并行生效、互不影响。

## 二开新增功能

### F1 · 自定义词库同步到自己的 GitHub 仓库

本机自定义关键词可存成你仓库里的一个 JSON 文件（如 `mxga-custom-rules.json`）：

- 本机新增 / 删除关键词 → 自动推送到仓库
- 在 GitHub 网页上直接编辑 → 每 6 小时自动合并回本机（也可手动「双向同步」立即拉取）
- 写入前强制鉴权：校验登录令牌对目标仓库的写权限，旧版登录令牌（仅 `read:user`）需退出重新登录
- 官方同步下来的关键词照常生效，两套词库互不影响

入口：设置 → 检测规则 → 自定义规则 → 「同步到我的 GitHub 仓库」

### F2 · 白名单改绑新的 X id

账号改名后，把已批准的官方白名单名额迁到新 id：

- 新 id 自动识别为当前登录的 X 账号（与首次申请同一套防滥用机制，不可手填、不可替别人改绑）
- 走与首次申请相同的 GitHub 身份鉴权 + 人工审核；批准时名额自动迁移，旧 id 同步退出白名单（保留审计）
- 官方服务器暂未部署自动改绑端点，扩展内提供预填好的 GitHub Issue 人工通道兜底；自部署 edge 后可全自动

入口：白名单页 → 已批准面板 → 「改绑新的 X id」

### F3 · 黑名单一键拉黑（严格限速）

把公共黑名单条目用你的 X 登录态批量原生拉黑，四层防风控设计：

| 层 | 机制 |
|---|---|
| 限速 | 后台泵 2.5s + 随机抖动，叠加底层 1.2s 限速队列与阶梯冷却，实际约 4-5 秒/个 |
| 限量执行 | 单次 100 / 300 / 500 可选，绝不整表跑 |
| 失败熔断 | 连续 5 次 X 报错自动停止 |

- 需保持一个打开的 x.com 标签页作为执行器（拉黑请求必须由 x.com 页面发出）
- 支持暂停 / 继续 / 停止；进度本地持久化，关浏览器不丢，1 分钟看门狗自动续跑
- 已处理过、白名单账号、你自己一律自动跳过；拉黑成功自动落账到「处理记录」

入口：概览页 → 「黑名单一键拉黑」任务卡

### F4 · X 原生拉黑列表同步与误操作恢复

识别你 X 账号**过往已经拉黑**的账号——新装扩展显示 0，点一下手动同步即可：

- 「同步拉黑列表」通过打开的 x.com 标签页分页拉取 X 的 `blocks/list.json`（只读，每页 200 个、页间自动停顿），数量 + 详细列表（头像 / 昵称 / @handle / ID）存本机
- 侧边栏独立「X 拉黑」页：仿处理记录的表格样式 + 搜索过滤
- **误操作恢复**：每行「解除拉黑」调用 X 的 `blocks/destroy.json`，与拉黑共用同一套限速队列，成功后立即生效并从列表移除
- 同步与解除都是只读/单账号操作，结果仅存本机不上传

入口：概览页 → 「本地 X 账号黑名单」卡片（同步入口）→ 侧边栏「X 拉黑」页（明细与解除）

### F5 · 「本地规则命中也执行我设定的动作」开关

默认关闭（关键词命中封顶为本地隐藏）。开启后规则命中按各类别设定的动作执行（含 X 静音 / 拉黑），仍受自动收录档位与「仅推文评论区」范围限制。

入口：设置 → 自动处理策略

### F6 · KOL 悬浮卡（上游目标 02）

悬停在 @handle 上 → 浮卡展示账号可信度信号：账号年龄、粉丝 / 关注 / 推文规模、赞粉比、均赞/推、认证与白名单标识，以及本地采样结论——原创比、主题集中度与综合可信分（四档着色：靠谱 / 一般 / 存疑 / 高风险）。数据全部读自页面自身（React fiber 桥）+ 浏览过程中的本地累积采样（转推标记、词频；只存计数不存原文），零联网查询（见 `docs/KOL-CARD-PLAN.md`）。

入口：设置 → 开关「KOL 悬浮卡」（下方可查看/清空本地采样画像）；使用时直接悬停任意 @handle

## 安装

```bash
# Chromium（Chrome / Edge / Brave / Arc）
# 1. 从 Releases 下载 filtrationX-v0.2.01-chrome-mv3.zip（或自行构建：cd extension && npm install && npm run build）
# 2. 解压后 chrome://extensions → 开启「开发者模式」→「加载已解压的扩展程序」
# 3. 访问 x.com，扩展自动开始工作
```

加载前建议先停用商店版 MXGA，避免两个扩展同时检测同一页面。

## 服务端（可选）

`services/edge` 新增 `POST /v1/whitelist/apply/rebind`：与首次申请同一套 GitHub 身份 + 反滥用栈，要求名下存在仍生效的已批准申请；配套迁移 `services/edge/migrations/2026-10-24-whitelist-rebind.sql`（`whitelist_requests.supersedes_handle` 列），审批通过时自动完成名额迁移。

不部署也不影响扩展的其他功能；自部署后在「设置 → 高级」把服务地址改成你的 Worker 即可启用全自动改绑。
